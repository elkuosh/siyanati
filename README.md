# صيانتي 🚗🏍️

تطبيق أندرويد (Flutter) لمتابعة صيانة العربيات والموتوسيكلات. كل البيانات بتتحفظ على الموبايل نفسه.

## المميزات
- **مركبات بلا حدود**: عربيات وموتوسيكلات، ولكل مركبة الماركة والموديل والسنة واللوحة والعداد ونوع البنزين.
- **جدول صيانة دورية جاهز** بيتضاف لوحده مع كل مركبة، وتقدر تعدله براحتك (كل كام كم أو كل كام شهر، واللي ييجي الأول):
  - عربية: زيت 5000 كم أو 6 شهور، فلاتر، فرامل، بوجيهات، ردياتير، كاتينة، كاوتش، بطارية…
  - موتوسيكل: زيت 2500 كم، تشحيم الجنزير، طقم الجنزير، بلوف، فرامل، بوجيه…
- **حالة كل بند بالألوان**: تمام / قرّب / متأخر، بالكيلو وبالأيام.
- **تنبيهات على الموبايل** قبل الميعاد بعدد أيام تختاره، وفي يوم الميعاد نفسه (الصيانة، والرخصة، والتأمين).
- **تسجيل الصيانات**: أكتر من بند في الزيارة الواحدة، وقطع الغيار والمصنعية لوحدهم، والورشة (بتفتكر أسماء الورش اللي سجلتها قبل كده)، والملاحظات.
- **البنزين**: اللترات والسعر والمبلغ (بيحسب الناقص لوحده)، ومعدل الاستهلاك كم/لتر ولكل 100 كم.
- **مصاريف تانية**: ترخيص، تأمين، مخالفات، غسيل، جراج، كارتة، أقساط…
- **التقارير**: الإجمالي حسب الفترة، والتوزيع، ورسم لآخر 12 شهر، والصيانات حسب النوع، والتكلفة لكل كيلو، والمقارنة بين المركبات.
- **السجل**: كل حاجة مترتبة بالشهر، مع فلتر وبحث.
- **نسخة احتياطية** تبعتها على واتساب أو Drive وترجعها في أي وقت.
- الوضع الغامق، والعملة قابلة للتغيير، وبيقبل الأرقام العربي (١٢٣) والإنجليزي.

## طريقة 1: تبني الـ APK على GitHub (من غير ما تسطب حاجة)
1. اعمل Repository جديد على GitHub وارفع فيه محتوى الفولدر ده كله (ومعاه فولدر `.github` المخفي).
2. روح على تبويب **Actions**. البناء هيشتغل لوحده، وياخد حوالي 5–8 دقايق.
3. لما يخلص، افتح الـ Run وحمّل **siyanati-apk** من تحت، وهتلاقي جواه `app-release.apk`.
4. انقله للموبايل وسطّبه (هيطلب منك تسمح بالتثبيت من مصادر غير معروفة).

## طريقة 2: تبنيه على جهازك
محتاج [Flutter](https://docs.flutter.dev/get-started/install) (3.27 أو أحدث) و Android Studio.

```bash
cd garage_log
flutter create --org com.rovana --project-name garage_log --platforms android .
dart run tool/setup.dart
flutter pub get
flutter run                  # لو الموبايل متوصل بالكابل
flutter build apk --release  # الملف: build/app/outputs/flutter-apk/app-release.apk
```

`tool/setup.dart` بيضيف صلاحيات الإشعارات، واسم التطبيق بالعربي، والأيقونة، وإعدادات Gradle اللي مكتبة الإشعارات محتاجاها.

## هيكل الكود
| الملف | الوظيفة |
|---|---|
| `lib/models.dart` | المركبة، والصيانة، والبند الدوري، والبنزين، والمصروف، وكتالوج أنواع الصيانة والمواعيد الافتراضية |
| `lib/db.dart` | قاعدة بيانات SQLite، والنسخ الاحتياطي، والاسترجاع |
| `lib/state.dart` | الحالة العامة، وحساب المواعيد والتكاليف، وجدولة التنبيهات |
| `lib/notifications.dart` | الإشعارات المحلية |
| `lib/screens/` | الشاشات: الرئيسية، والمركبات، وتفاصيل المركبة، والنماذج، والسجل، والتقارير، والإعدادات |

## ملاحظات
- **ضغطة طويلة** على أي صيانة أو تفويلة أو مصروف بتمسحه، وضغطة عادية بتفتحه للتعديل.
- لما تسجل صيانة من نوع معين (زي تغيير الزيت)، ميعاد البند ده بيتحسب من جديد لوحده.
- لو بتدخل مركبة قديمة، افتح كل بند دوري واكتب "آخر مرة اتعملت" عشان المواعيد تتحسب صح.
- التنبيهات بالتاريخ بتتجدول على الموبايل. أما المواعيد بالكيلومتر فبتظهر جوه التطبيق، فحدّث العداد كل فترة أو سجّل تفويلاتك.
